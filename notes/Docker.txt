* List all docker images:
docker images

* To remove: 
docker rmi $(docker images -q)

* Remove all <none> tagged images: 
docker rmi $(docker images | grep "none"  | awk '{print $3}')

* List all non-kubernetes images: 
docker images | awk '$1 !~ /kube|k8s/ {print}'

Build:
docker build -f docker/Dockerfile -t <name> .


docker ps:
List running instances of a docker image (containers).
* Stop/remove all containers: 
docker stop $(docker ps -a -q) && docker rm $(docker ps -a -q)


docker-compose:
Creates docker images using a YAML file.
* docker-compose -f <file> build
* docker-compose -f <file> up
* docker-compose -f <file> down


start/stop container
docker stop <container ID>
docker start -ai <container ID> 	(-ai follows output)


Authenticate against ECR:
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 927185244192.dkr.ecr.us-east-1.amazonaws.com
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 127403002470.dkr.ecr.us-east-1.amazonaws.com


Attach to container and log in:
docker exec -it <container> bash

Attach to container after getting containerId:
docker exec -it $(docker ps | grep 'mercury-test-queued' | awk '{print $1'}) bash


Run docker images and log in:
docker run -it --entrypoint bash <image>
docker run -v "C:/projects/mercury:/mercury" -it --entrypoint bash 9ef86393bfda


Copy file from image:
docker create $image 
docker cp $container_id:$source_path $destination_path
docker rm $container_id


Docker Volumes list and remove all unused:
docker volume ls
docker volume prune

docker run --env-file docker/env.list -p 8667:667 -p 9011:9011 mercury-queued-local

docker run --env-file docker/env.list -v "C:\projects\sonus":/sonus mercury-sonus-local
